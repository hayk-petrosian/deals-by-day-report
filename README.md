# Отчёт «Новые сделки по дням»

Отдельный проект, не связанный с Todo List.

## Работа с отчётом

- Выбираются любые начальная и конечная даты; ограничения в 7 дней нет.
- По кнопке «Показать отчёт» сайт запрашивает список сделок Bitrix24 постранично и строит гистограмму по дням.
- В браузер передаются только дневные итоги; имена, контакты, названия сделок и суммы не выбираются.
- Дни без сделок тоже показываются. Группировка выполняется в часовом поясе устройства.

## Архитектура и доступ

GitHub Pages сам по себе не запускает серверный код, поэтому API размещается отдельно на Cloudflare Pages Functions. Вебхук хранится только в Cloudflare secret `BITRIX_WEBHOOK_URL`; пароль руководителей — в `REPORT_PASSWORD`; для подписи коротких сессий — случайный `SESSION_SECRET`. Ни один из этих секретов нельзя коммитить в GitHub.

На сайте требуется пароль длиной не менее 16 символов. После входа сервер выдаёт подписанную сессию в `Secure`, `HttpOnly`, `SameSite=Strict` cookie. API выполняет только `crm.item.list` для `entityTypeId: 2` и агрегирует даты на сервере. В ответ браузеру не отправляются исходные записи сделок.

## Публикация

Cloudflare Pages нужно подключить к этому репозиторию с корнем проекта `/`, без команды сборки, и указать корневую папку вывода. Папка `functions/` автоматически включает Pages Functions. В настройках проекта добавьте три переменные как **Secrets**:

- `BITRIX_WEBHOOK_URL` — полный HTTPS URL входящего вебхука портала;
- `REPORT_PASSWORD` — случайный пароль не короче 16 символов для руководителей;
- `SESSION_SECRET` — случайная строка не короче 32 символов.

После первой публикации используйте домен `*.pages.dev` как рабочий сайт. Код для GitHub Pages не содержит API-секрета; GitHub Pages не может запустить `functions/`.

## Проверка

Запустите `npm test` для проверки авторизации, доступа к API, фильтра дат без ограничения в 7 дней, постраничной обработки и агрегации ответов Bitrix24.

Для работы с реальными сделками нужны секреты окружения и запущенный Cloudflare Pages deployment. Не вставляйте вебхук в `index.html`, `app.js`, README или открытые настройки GitHub.
