# Отчёт «Новые сделки по дням»

Отдельное статическое приложение для Bitrix24. Не связано с Todo List.

## Что показывает отчёт

- число созданных сделок по дням в виде гистограммы;
- период от 1 до 7 календарных дней включительно;
- нулевые дни тоже отображаются;
- выгружается только поле `createdTime`, названия, контакты и суммы не запрашиваются.

## Доступ и безопасность

Приложение не содержит вебхук, пароль или OAuth-секрет. При запуске внутри Bitrix24 используется авторизация текущего пользователя; Bitrix применяет его обычные права на CRM. Сама публичная страница не загружает CRM-данные вне Bitrix24.

Для отчёта нужен доступ на чтение CRM. Назначать доступ к приложению следует только тем сотрудникам, которым разрешён этот отчёт.

## Публикация

Это статический сайт: разместите папку на публичном HTTPS-хостинге. Для встраивания Bitrix24 в настройках хостинга не должны запрещаться iframe-запросы с домена вашего портала. Перед подключением проверьте, что публичная страница открывается по HTTPS.

## Подключение к Bitrix24

1. В Bitrix24 откройте раздел локальных приложений для разработчиков и создайте статическое локальное приложение.
2. Укажите публичный HTTPS-адрес `index.html` как адрес обработчика приложения.
3. Включите только область доступа `crm` (для чтения сделок) и задайте название, например «Новые сделки по дням».
4. Сохраните и установите приложение. Ограничьте список пользователей теми руководителями, которым нужен отчёт.
5. Откройте приложение из раздела приложений в главном меню Bitrix24.

Регистрация приложения и установка требуют соответствующих прав администратора Bitrix24. Приложение использует официальный метод `crm.item.list` (`entityTypeId: 2`) и системное поле `createdTime`.

## Разработка локально

Откройте `index.html` напрямую в браузере, чтобы посмотреть интерфейс. Для получения данных страница должна быть установлена и запущена внутри Bitrix24.
